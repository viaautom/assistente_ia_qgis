about=AI assistant inside QGIS. Chat in a side panel (interface in Portuguese): the plugin collects the project context (layers, CRS, fields — feature data is never sent), asks Claude for PyQGIS code, shows the code before running it and only executes it after your confirmation. Dangerous operations are blocked and errors are corrected automatically. Requires your own Anthropic API key (console.anthropic.com); API usage costs are paid by the user. The key is stored in the QGIS Authentication Manager. Developed by Ibexdev. / Assistente de IA para QGIS em português: descreva o que deseja fazer e o plugin gera e executa código PyQGIS com sua confirmação.
